천심원 사무국에서 개최하는 3일 공명기도 수련 소감문을 엑셀에서 워드로 변환하는 프로그램.

===사용방법===

1. 엑셀 파일이 담긴 폴더를 선택한다.

2. 엑셀파일별로 추출할 번호를 입력한다.

3. 최소 추출 길이를 설정한다. 기본값 30

4. 엑셀->json으로 변환 버튼을 눌러 추출한다. 추출된 파일은 선택한 파일 경로와 동일하며 파일명_json_output 가 생성된다.

5. 추출된 json을 그대로 AI에게 파일째로 넘겨서 문장 오타검수를 한다.

6. AI가 해준 json 포맷 그대로 원본 json에 복사 붙혀넣기 한다.

7. json -> word 변환 버튼을 누른다.

8. 원본 파일 경로로 들어가면 word로 변환된 파일명_word_output 이 생성된다.

===추천 프롬프트===

json 파일의 형식을 준수해. 문장의 분위기와 고유명사를 유지하면서 문장의 오타와 문법오류만 교정하되 정중한 말투로 교정해. 일본어는 한국어로 번역해. 출처 번호나 링크 기재 없이 본문 내용만 깔끔하게 답변해 줘.
